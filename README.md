## Run locally

This is a static HTML website. You can preview it locally by opening `index.html` in a browser. No backend service or package installation is required for the current static pages.

## GitHub Pages deployment

To publish this project with GitHub Pages:

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the branch containing the website files and choose the `/(root)` folder.
4. Save and wait for the Pages deployment workflow to complete.

The current portfolio and resume updates are on the `prototype/resume-portfolio-v1` branch. Make sure GitHub Pages is configured to publish that branch, or merge the changes into the branch configured for publishing.
